
# StockMarket - CCA2 CD Project

## Project Overview
StockMarket is a simple, responsive stock market dashboard developed using HTML, CSS, and JavaScript.

## Features
- Market overview dashboard
- NIFTY 50, SENSEX, NASDAQ, and gold demo values
- Add stocks to a watchlist
- Remove stocks from the watchlist
- Market news and investment awareness section
- Responsive layout for desktop and mobile devices

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git and GitHub
- Jenkins
- CI/CD Pipeline

## Project Structure
- stockmarket.html - Main website
- README.md - Project documentation
- Jenkinsfile - Jenkins pipeline configuration

## Run Locally
1. Download or clone this repository.
2. Open stockmarket.html in a web browser.
3. Add or remove stocks using the watchlist.

## CI/CD Workflow
1. Store project source code in GitHub.
2. Use Jenkins to check out the repository.
3. Validate that the HTML file exists and contains HTML markup.
4. Archive the HTML file as a build artifact.

## Important Note
Market values and news on this website are demonstration content.
They are not live market data or investment advice.
